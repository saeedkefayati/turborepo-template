# Design System Testing

The UI package integrates Storybook with Vitest browser testing.

Run the Storybook test suite with:

```bash
pnpm --filter @repo/ui test-storybook
```

Story interactions are used to validate component behavior in a browser environment.

The pre-push quality gate runs the UI test suite together with the Storybook production build.

Testing should focus on externally observable component behavior rather than internal implementation details.
