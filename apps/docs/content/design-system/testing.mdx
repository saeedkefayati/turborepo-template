# Design System Testing

The UI package integrates Storybook with Vitest browser testing.

The repository-wide test contract is:

```bash
pnpm test
```

The current implementation discovers the UI test task and runs Storybook tests
with Vitest, Playwright, and Chromium.

For targeted UI development, run:

```bash
pnpm --filter @repo/ui test
```

Story interactions validate externally observable component behavior in a real
browser environment.

The pre-commit hook conditionally runs the targeted UI test task when matching
UI files are staged.

The pre-push and remote CI layers consume the repository-wide `pnpm test`
contract.

Future workspace test suites can participate by defining their own `test` task
without changing the root command.
