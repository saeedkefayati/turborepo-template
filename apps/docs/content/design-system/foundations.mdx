# Design Foundations

The shared UI package contains reusable design foundations that establish consistent visual behavior across components.

Current foundation areas include:

- colors
- typography
- spacing
- border radius
- shadows
- motion

Each foundation is documented and previewed through Storybook.

Foundations should remain independent of individual product screens and should expose reusable design decisions that can be consumed consistently across applications.
